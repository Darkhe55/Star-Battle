# 星之战 Star Battle

一个基于 Web 的星之战（Star Battle）谜题游戏，原生 SVG 渲染，内置逻辑解题器。

## 在线体验

```bash
npm install
npm start
```

`npm start` 会等开发服务就绪后用默认浏览器打开 **http://127.0.0.1:5185/**。

> 也可以用 `npm run dev`，但不会自动打开浏览器。

## 游戏规则

- 每行、每列、每个粗线区域各放恰好 K 颗星
- 任意两颗星不能横向、纵向或斜向相邻
- 数字 K 显示在题目信息中

## 操作

| 操作 | 说明 |
|------|------|
| 左键点格 | 循环：空 → 星 → 叉 → 空 |
| 右键点格 | 直接标叉 / 清除 |
| 按住拖动 | 连续涂写 |
| 滚轮 / 中键拖拽 | 缩放 / 平移画布 |
| Z / Shift+Z / Y | 撤销 / 重做 |
| C / H / S / Esc | 检查 / 提示一格 / 显示解 / 清空 |
| R / L / P / M | 随机抽题 / 逻辑解题 / 暂停回放 / 音效开关 |
| 0 / + / - | 视图复位 / 放大 / 缩小 |

## 数据存放

运行 `npm start` / `npm run dev` 时，题库、进度和上次题目保存在项目内 `data/` 目录；静态部署时自动降级到浏览器 localStorage。

## 功能

- **题库**：内置多道题，题目均校验唯一解
- **自定义题板**：在侧边栏编辑题面，载入后即可游玩，支持保存、编辑、删除与唯一解校验
- **实时校验**：冲突与违规位置即时高亮，满足的条件同步变灰
- **逻辑解题**：规则引擎逐帧回放，显示每一步理由；优先使用可证明的安全定式，推不动时才反证 / 回溯；回放中按钮变为停止，按 `P` 暂停/继续
- **提示一格 / 显示解**：提示优先揭示所有解一致的格子，显示解直接填入可行答案
- **撤销/重做**：按手势分组，一次拖拽只需一步撤销
- **进度保存**：自动保存当前题目进度，刷新不丢失
- **音效特效**：Web Audio 合成拨弦、水滴与落子动画，无外部音频资源
- **缩放/平移**：滚轮缩放，中键或 `Shift` 拖拽平移

## 逻辑解题规则（安全定式）

逻辑引擎只做**可证明的局部约束**（只排除一定不成立的候选），不做猜测；反证与回溯仅作兜底：

| 规则名 | 说明 |
|--------|------|
| 八邻接 `adj` | 星星的横、竖、斜向相邻格不能放星 |
| 2×2 至多 1 星 `block` | 任意 2×2 内至多 1 颗星（与八邻接等价，作为独立局部检查） |
| 行 / 列 / 区域配额 `count` | 每行 / 列 / 区域恰好 K 颗星：已满则其余标叉，候选数刚好够则全部放星 |
| 单元候选排列 `unit` | 枚举行 / 列 / 区域内所有「恰好 K 颗、两两不八邻接」的摆法：所有摆法都含的格强制放星，都不含的格排除 |
| 双行 / 双列带枚举 `band` | 枚举相邻两行 / 两列内满足配额、互不八邻接、且不超过区域剩余配额的摆法并取交集；≤12×12 盘面启用 |
| 区域-行列 Hall 约束 `hall` | 一组区域的可选格若全落在同样需求的行 / 列集合里，则这些行 / 列的星只能来自这些区域：需求相等时其余区域在这些行 / 列上的格排除，需求超出即矛盾 |

- 兜底顺序：定式推满 → 逐格反证（`probe`）→ 回溯搜索（`search`）。
- 内置 6 题均可推满（`npm run check` 0 警告）；10×10 K=2 两题仍需逐格反证，但唯一解搜索节点从 9777 / 6705 降到 77 / 111。
- 限制：>12×12 盘面跳过双行 / 双列带枚举（组合数过大），超大棋盘（如 30×30）的逻辑回放可能较慢。

## 技术栈

- Vite + TypeScript
- 原生 SVG（无框架）
- Web Audio 合成音效（无外部资源）
- localStorage / 项目内 `data/` 存储进度与题库

## 图片导入

`npm run import-image -- <图片路径>` 可以自动识别星之战（Star Battle）题图：黑像素投影定位网格线，按每条边界的线宽区分细线（普通网格）与粗线（区域边界），四连通洪泛得到区域编号。

```bash
npm run import-image -- 题图.png --dry                     # 只识别与预览
npm run import-image -- 题图.png --name "我的星之战" --append     # 追加到题库
npm run import-image -- 题图.png --append --verify --stars 2   # 2★ 变体 + 唯一解检查
```

| 参数 | 说明 |
|------|------|
| `--size N` / `--width W --height H` | 覆盖棋盘尺寸 |
| `--stars K` | 每行/列/区域的星星数（默认 1） |
| `--thick N` | 手动指定细/粗线阈值（区域识别不准时） |
| `--name` / `--id` | 题库名字 / id |
| `--append` / `--verify` / `--dry` | 写入题库 / 唯一解检查 / 只识别 |

## 题板尺寸与形状支持

- **题面模型**：每格区域号 + 每行/列/区域星星数 K，`width × height`。
- **形状约束**：规则要求每行、每列、每个区域各 K 颗星 ⇒ 总星数 = K×宽 = K×高 ⇒ **宽必须等于高**。
  因此本项目只支持**正方形**题板，非正方形星之战在规则上无解（不是实现缺失）。
- **内置题库**：6×6～10×10 正方形（含 10×10、K=2 变体）。
- **自定义题板**：宽 5–30、高 5–30；请把宽高填成相同值（编辑器允许不同，但非正方形无解）。
  本次修改把**区域编号上限从 9 提到 35**：1–9 用数字键，10–35 用字母键 `a`–`z` 直填
  （此前自定义题板只能画 1–9 号区域，≥10×10 的题板区域数不够，实际画不出有效题）。
- **识图导入**：25×25 大图自动识别成功（25 个区域、K=1）。
- **异形棋盘**：不支持（行/列/区域三个视角都是整行整列，没有外部空格语义）。
- **验证**：`npm run build`、`npm run check` 通过；内置题参考解与逻辑计划合法；
  10×10 内建题（10 个区域）经自定义编辑器回填后编解码往返、求解合法，
  浏览器实测字母键 `a` 落到格子显示 `a`（`r10` 配色类）；30×5 / 5×30 极限尺寸渲染正常（但无解属规则限制）。
- **限制**：30×30 求解/逻辑回放可能很慢（有节点/时间上限）；>12×12 跳过双行/双列带枚举；
  大盘面区域数超过 35 时无法用自定义题板表达。
